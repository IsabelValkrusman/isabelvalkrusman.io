Google Play ↗

ABOUT

Road trip through the Baltics

Route 66 Via Baltica is an Android travel application designed around the Via Baltica route.

The application helps users discover interesting places, restaurants and tourist attractions along the route.

Users can explore different countries, view locations on a map and add their own places.

FEATURES

01

Interactive Map

Explore places along the Via Baltica route using Google Maps.

02

Country Navigation

Explore Estonia, Latvia, Lithuania and Poland.

03

Places & Attractions

Discover restaurants, tourist attractions and other useful locations.

04

User Added Places

Users can add and save their own locations.

TECHNOLOGIES

Kotlin Android Studio Jetpack Google Maps API Local Database
